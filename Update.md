### Total Dataset

We will be ordering scenes month by month (1-12) for all nine years

- $9$ (years) $* 12$ months = **108** scenes total
- $9$ (years) $* 17,592 kms$ = **158325651** $m^2$
- **Pixel Resolution:** 10m x 10m
- 40475.0479063
- **Patch Size:** 256px \* 256px

- This is a larger undertaking, and is going to be island wide, this means that we will have to be agile with our data collection and not make any mistakes
- To solve this we are going to be use RTC (Radiometrically Terrain Corrected), this allows for some of the topological effects like shadows to be removed allowing for a more uniform collection
- We are following the advice of, [Mapping wetland characteristics using temporally dense Sentinel-1 and Sentinel-2 data: A case study in the St. Lucia wetlands, South Africa] we take different distribution of the Sentinel-1 data for each monthly patch collection to allow us to reduce noise and imperfections.
- All coordinate will be transformed to EPSG Code 32604
